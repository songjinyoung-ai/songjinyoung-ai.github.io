# 잘 작성된 메모리 파일이란

## 확인된 구성

- 안드레 카파시의 skill 자료
- `CLAUDE.md`와 `AGENTS.md`
- 원문 자료
- 한국어 의역본

## JY Lab 적용 메모

메모리 파일은 모든 내용을 쌓는 장소가 아니라, 다음 작업에도 반복해서 필요한 프로젝트 규칙과 결정 사항을 남기는 장소로 관리한다.

- 프로젝트 목적과 범위
- 자주 쓰는 명령어
- 확정된 설계 결정
- 검증 방법
- 반복해서 발생하는 환경 문제
- 아직 미확정인 사항

원본 페이지의 코드 블록은 추가 확인 후 별도 파일로 가져온다.
